# Legacy artifacts (do not use)

These are the model files that shipped with the original repository. They are
kept only for provenance and are **not** loadable by the current pipeline.

| file | problem |
|---|---|
| `dnn_model.h5` | Keras 2 HDF5 format; trained by a Colab run that is not in this repo. |
| `GaussianNB_model (1).pkl` | Filename with a space and a browser `(1)` duplicate marker. |
| `scaler_legacy.pkl` | Fitted on 30 features chosen with test-set leakage. |

Why they were replaced:

* They were produced by an **unsaved** training run. Neither `notebooks/Code.ipynb`
  nor `notebooks/EE708_project.ipynb` can regenerate them - both notebooks run on
  a different dataset (Polish `Attr1..Attr64`), while these artifacts expect the
  Taiwan feature names in `data/raw/Train.csv`.
* Scored against the whole of `Train.csv` - data they were partly fitted on - the
  saved DNN reports F1 = 0.87, which is memorisation, not performance.
* The feature list they depend on was selected on the full dataset, so the
  scaler and both models carry test-set information.

Current artifacts live in `models/saved/` and are regenerated by
`python src/train.py`.
