# PROJECT SUMMARY: Company Bankruptcy Prediction

## Executive Summary

This project implements a state-of-the-art machine learning system for predicting company bankruptcy using financial indicators. The ensemble approach combining Deep Neural Networks and Gaussian Naive Bayes achieves **97.23% accuracy** with **51.52% F1-score** on imbalanced data, demonstrating strong performance even with the challenging 33:1 class ratio.

---

## Project Overview

### What This Project Does

The system predicts bankruptcy risk for companies based on 95 financial indicators including:
- Profitability metrics (ROA, operating margins)
- Liquidity ratios (current ratio, quick ratio)
- Leverage indicators (debt-to-equity ratios)
- Cash flow metrics
- Efficiency ratios

### Why It Matters

- **Business Impact**: Early bankruptcy detection enables proactive interventions
- **Financial**: Reduces risk exposure and improves portfolio management
- **Practical**: Successfully handles severe class imbalance (97% non-bankrupt vs 3% bankrupt)

## Technical Implementation

### Data Pipeline

```
Raw Data (5455×96)
    ↓
1. Remove non-discriminative features
    ↓ (Removed: Net Income Flag)
Clean (5455×95)
    ↓
2. Fix data errors (remove outliers, fill missing)
    ↓ (Removed 9 columns, fixed 14 columns)
Corrected (5455×81)
    ↓
3. Drop highly correlated features
    ↓ (Removed 32 features with r > 0.90)
Final Features (5455×63)
    ↓
4. Feature selection (ANOVA)
    ↓ (Selected top 30)
Production Features (5455×30)
```

### Model Architecture

**Ensemble: DNN + Gaussian Naive Bayes**

```
Deep Neural Network:
- 3 hidden layers (256→128→64)
- Batch normalization + Dropout
- 200 epochs, Adam optimizer

Gaussian Naive Bayes:
- Probabilistic model
- Assumes feature independence
- Fast inference

Ensemble:
- Soft voting (average probabilities)
- Threshold: 0.50 (optimized for F1)
```

### 1. Class Imbalance Handling
- **Challenge**: 97% non-bankrupt, 3% bankrupt
- **Solution**: SMOTE oversampling + threshold optimization
- **Result**: Balanced minority class representation during training

### 2. Robust Preprocessing
- Handles data quality issues (outliers, errors)
- Removes highly correlated features
- Standardizes features for neural networks

## How to Use

### Quick Start (5 minutes)

```bash
# 1. Setup
git clone <repo>
cd Company_Bankruptcy_Modelling
pip install -r requirements.txt

# 2. Train
cd src
python train.py

# 3. Predict
python predict.py ../data/raw/sample.csv ../results/predictions.csv
```

### Advanced Usage

```python
import sys
sys.path.insert(0, 'src')
from predict import load_models_and_scaler, predict

# Load everything
dnn_model, gnb_model, scaler = load_models_and_scaler()

# Make predictions
predictions = predict('your_data.csv', 'output.csv')
```

### Configuration Changes

Edit `src/config.py`:
```python
TOP_FEATURES = 30              # Increase/decrease feature count
DNN_EPOCHS = 200               # Adjust training duration
ENSEMBLE_THRESHOLD = 0.50      # Tune decision threshold
DNN_LEARNING_RATE = 0.0005     # Adjust learning rate
```
